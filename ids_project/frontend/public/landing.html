The Detection Paradox

Why Traditional Rules Fail Against Modern LAN Exploits

Static IP-MAC lookup tables can be bypassed with address rotation, while standard machine learning engines struggle with zero-day false positives without human verification.

Legacy Vulnerability

Traditional Static Firewalls

  • ✕
    Address Rotation Vulnerability: Attackers rotate source IPs dynamically to bypass fixed static binding tables.
  • ✕
    Zero Temporal Context: Unable to calculate burst ratios, churn deltas, or unsolicited reply spikes over 30s/60s sliding windows.
  • ✕
    Alert Fatigue: Floods security administrators with unranked logs lacking probability confidence scores.
Intelligent Hybrid Engine

ARP Security Box Defense

  • ✓
    Feature-Based Generalization: Evaluates 10 non-linear metrics to identify anomalies regardless of IP/MAC spoofing.
  • ✓
    Active Learning Pipeline: Human administrator decisions on borderline edge packets retrain the local model dynamically.
  • ✓
    Self-Healing Table Flushes: Purges poisoned cache bindings and triggers rapid subnet re-scans instantly.
Execution Pipeline

End-to-End Threat Processing Workflow

From passive SPAN ingestion to real-time classification and automated containment.

01

Packet Ingestion & Feature Extraction

The sniffer daemon passively reads raw Layer-2 Ethernet frames from the switch mirror port and computes 10-dimensional metric vectors across rolling time frames.

requests_60s > 20 && ip_mac_churn_delta == 1
02

Hybrid Priority Scoring

Immediate rule checks execute for high-severity known signatures (gratuitous bursts & scanning). Ambiguous traffic triggers the XGBoost inference engine for probabilistic anomaly scoring.

Score ≥ 0.70 → Immediate Alert • Score 0.40 - 0.70 → Review Queue
03

Analyst Verification & Retraining

Borderline detections route to the Analyst Review Queue. Validated labels automatically feed back to optimize XGBoost decision boundaries on-premises.

True Positives → Dataset Augment • False Positives → Suppress
